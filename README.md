- اللوحة: https://monawaat.web.app/dashboard/

## أول تشغيل (خطوات لمرة واحدة)

1. **تفعيل الدخول بالإيميل** في كونسول فايربيز:
   Authentication → Sign-in method → **Email/Password** → Enable.
2. **افتح اللوحة** — هتلاقي "إعداد حساب المالك". أول حساب بيتعمل هو المالك بكل الصلاحيات.
3. **الهوية** من اللوحة: هوية المحل → الاسم واللوجو والألوان والخلفية.
4. **بوت تليجرام جديد** من BotFather → الإعدادات → بوت تليجرام → التوكن → Start مع البوت → اربط الشات.
5. **وركر الإشعارات**: من اللوحة → الأدمن → وركر الإشعارات → "إنشاء الحساب وتنزيل config.json"،
   حط الملف في `push-worker/` وشغّل `install.bat` مرة ثم `start.bat`.
