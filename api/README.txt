وركر الإشعارات على فيرسل — بديل مجاني لـ Cloud Functions
=========================================================

الملف worker.mjs دالة serverless بتعمل دورة واحدة كل مرة تتنادى:
  • كل طلب جديد لسه ماتبعتش عنه رسالة  ⇒  رسالة تليجرام للمحل (بصورة التحويل)
  • كل طلب حالته اتغيّرت              ⇒  سطر للمحل ورسالة للعميل لو رابط البوت

مفيش ملف حالة: العلامات نفسها في قاعدة البيانات (`telegramSent` و
`notifiedStatus` جوّه الطلب)، فمهما اتنادت الدالة مفيش رسايل مكررة.


التشغيل
-------
1) متغيّرات البيئة في فيرسل (Settings → Environment Variables → Production):

   CRON_SECRET     كلمة سر عشوائية (اتظبّطت خلاص)
   WORKER_CONFIG   نفس إعدادات وركر بايثون، سطر واحد JSON:

   {"projects":[
     {"name":"منوعات عباد الرحمان",
      "databaseUrl":"https://alih-5212b-default-rtdb.firebaseio.com",
      "apiKey":"AIza...",
      "email":"<إيميل حساب الوركر>",
      "password":"<باسوردة>"},
     {"name":"المحل التاني","databaseUrl":"...","apiKey":"...",
      "email":"...","password":"..."}
   ]}

   بيانات كل محل موجودة في config.json اللي بتنزّله من لوحته:
   الأدمن ← وركر الإشعارات ← "إنشاء الحساب وتنزيل config.json".

2) اعمل Redeploy بعد ما تحط المتغيّرات (المتغيّرات بتتفعّل مع نشر جديد).

3) كرون خارجي مجاني ينادي الرابط كل دقيقة — cron-job.org أو أي خدمة شبهها:

   https://monawaat.vercel.app/api/worker?key=<CRON_SECRET>

   (خطة فيرسل المجانية بتشغّل الكرون بتاعها مرة في اليوم بس، عشان كده
    بنستخدم كرون خارجي. الرابط مجرد طلب HTTP عادي.)


الاختبار
--------
   curl "https://monawaat.vercel.app/api/worker?key=<CRON_SECRET>"

   الرد المتوقّع:
   {"ok":true,"at":...,"results":[{"name":"...","newOrders":0,"statusUpdates":0}]}

   من غير مفتاح بيرد 401، ولو محل بياناته غلط بيرجّع خطأه لوحده
   والباقي بيكمّل عادي.


فرق عن وركر بايثون (push-worker/)
----------------------------------
الدالة دي بتعمل تليجرام بس. إشعارات Web Push للعملاء لسه محتاجة وركر
بايثون (محتاج توقيع VAPID). لو عايز الاتنين: شغّل بايثون على استضافة
مجانية (شوف push-worker/README.txt) — أو سيب دي للطلبات الجديدة وخلاص.
