منوعات عباد الرحمان — سيرفر الإشعارات (بايثون)
=====================================

بيعمل كل اللي كان محتاج سيرفر مدفوع، من على جهازك:

  • إشعارات Push للعملاء (منتج جديد / خصم / حالة الطلب) — حتى والموقع مقفول
  • رسايل تليجرام لكل طلب جديد وكل تغيير حالة
  • رفع صور الداش بورد على Google Drive (اختياري)

مفيش Firebase Blaze، ومفيش Cloud Functions، ومفيش حساب خدمة.


التشغيل
-------
1) من لوحة التحكم: الأدمن ← وركر الإشعارات ← "إنشاء الحساب وتنزيل config.json"
2) حط config.json هنا جنب worker.py
3) install.bat     ← مرة واحدة، بيثبّت مكتبات بايثون
4) start.bat       ← شغّله وسيبه مفتوح

(الوركر بيدخل بحساب موظف محدود الصلاحيات — مش حساب المالك.)


Drive (اختياري)
---------------
1) Google Cloud Console → فعّل "Google Drive API"
2) Credentials → OAuth client ID → نوع "Desktop app" → نزّل الملف
3) حطه هنا باسم client_secret.json
4) في config.json خلي:  "drive": { "enabled": true }
5) في الداش بورد → الإشعارات والتطبيق: فعّل رفع الصور على Drive

من غير الخطوات دي الصور بتتحفظ مضغوطة جوه قاعدة البيانات وبتشتغل عادي.


ملفات مهمة
----------
config.json        إعداداتك ومفاتيح الإشعارات  (متمسحش — لو اتمسح كل المشتركين هيحتاجوا يفعّلوا الإشعارات تاني)
state.json         آخر طلب/إشعار اتبعت (عشان مايتكررش)

أكتر من محل في نفس الوركر
--------------------------
الوركر بيشغّل كذا مشروع فايربيز مع بعض. غيّر config.json للشكل ده:

  {
    "pollSeconds": 5,
    "vapidSubject": "mailto:owner@example.com",
    "projects": [
      { "name": "منوعات عباد الرحمان", "databaseUrl": "...", "apiKey": "...",
        "email": "...", "password": "...", "vapid": { "public": "...", "private": "..." } },
      { "name": "المحل التاني", "databaseUrl": "...", "apiKey": "...",
        "email": "...", "password": "...", "vapid": { "public": "...", "private": "..." } }
    ]
  }

  • كل مشروع بياناته لوحده (نزّل config.json من لوحة كل محل وانقل منه).
  • أي مفتاح بتحطه بره "projects" بيتورّث للكل (زي pollSeconds و vapidSubject).
  • الشكل القديم (مشروع واحد في الجذر) لسه شغال زي ما هو.
  • كل سطر في الشاشة بيتعلّم باسم المحل، ولو محل وقع الباقي بيكمّل عادي.
  • state.json بقى بيفصل حالة كل محل لوحده (بيتحوّل تلقائياً من الشكل القديم).


تشغيله مجاناً على النت (من غير ما تسيب جهازك مفتوح)
----------------------------------------------------
1) ارفع المشروع على GitHub.
2) render.com → New → Blueprint → اختار الريبو (بيقرا render.yaml لوحده).
3) في Environment حط متغيّر اسمه WORKER_CONFIG وقيمته محتوى config.json
   كامل (نسخ ولصق). كده الأسرار مش في الكود ولا في الريبو.
4) الخطة المجانية بتنوّم الخدمة لو محدش فتحها ١٥ دقيقة — سجّل رابط الخدمة
   في cron-job.org (مجاني) كل ١٠ دقايق فيفضل صاحي.

الوركر بيفتح صفحة حالة على "/" لما يلاقي متغيّر PORT (الاستضافة بتحطه
لوحدها)، وبترجّع أسماء المحلات الشغالة — نفس الرابط اللي بيصحّيه.
